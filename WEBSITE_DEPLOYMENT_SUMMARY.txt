🚀 DEPLOY IN 5 MINUTES
════════════════════════════════════════════════════════════════════════════

OPTION 1: AWS S3 (Recommended) ⭐
────────────────────────────────
Advantages:
  ✅ Global CDN
  ✅ HTTPS included
  ✅ Very fast
  ✅ Auto-scaling
  ✅ Only $5/month
  ✅ No maintenance

Steps:
  1. Install AWS CLI: pip install awscli
  2. Configure: aws configure
  3. Deploy: bash deploy-docs.sh s3
  4. Your docs live at: http://escrow-docs.s3-website-us-east-1.amazonaws.com/
  5. (Optional) Set up CloudFront for custom domain

Time: 5 minutes
Cost: ~$5/month


OPTION 2: Local Testing (Fastest)
──────────────────────────────────
Perfect for:
  ✅ Testing before deploying
  ✅ Team review
  ✅ Development

Steps:
  1. bash deploy-docs.sh local
  2. Open browser: http://localhost:8000
  3. Done!

Time: 2 minutes
Cost: Free


OPTION 3: Nginx (On Existing Server)
─────────────────────────────────────
Advantages:
  ✅ Keep docs with API
  ✅ No additional costs
  ✅ Single point of access

Steps:
  1. bash deploy-docs.sh nginx
  2. Follow prompts
  3. Docs available at: https://api.eascrow.io/docs/

Time: 10 minutes
Cost: Free

🆘 TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════

Problem: "AWS CLI not found"
Solution: pip install awscli

Problem: "Website won't load"
Solution: Check deployment completed successfully
         Check files uploaded with: aws s3 ls s3://escrow-docs/

Problem: "Styles look broken"
Solution: Clear browser cache (Ctrl+Shift+Del)
         Try different browser
         Check mobile view

Problem: "Page is slow"
Solution: If using S3, create CloudFront distribution
         If using Nginx, enable caching
