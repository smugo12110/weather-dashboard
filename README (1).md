# East African Cross-Border Escrow MVP Engine & Frontend Client

This architectural bundle provides a fully functional developer sandbox setup engineered specifically to circumvent primary regulatory and technical access entry barriers in the East African financial territory.

## Project Framework Structure
* `/src/index.js` - Backend Express.js controller engine processing mathematical exchange vectors, incoming webhook checks, outbound idempotent wallet payouts, and offline telecommunication fallback channels (USSD).
* `/index.html` - Minimal operational administration dashboard optimized using Tailwind frameworks to trigger and track transactions locally.

## Setup Requirements & Installation Actions
1. Open your native machine command line dashboard inside the workspace root module.
2. Trigger dependency resolution checks by executing:
   ```bash
   npm install
   ```
3. Create your runtime configuration environmental file map by duplicating the tracking example configuration:
   ```bash
   cp .env.example .env
   ```
4. Configure sandbox api access properties inside `.env` using keys generated instantly from your developer configurations inside Flutterwave and Africa's Talking.
5. Initialize runtime procedures by executing the server start configuration wrapper:
   ```bash
   npm start
   ```
6. Double-click or serve `index.html` inside any standard internet navigation client browser layout to access administration dashboards.
